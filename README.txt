IMOVIEWER

Como abrir:
1. Abra a pasta "avaliador-imoveis".
2. Dê dois cliques no arquivo "index.html".

Não é necessário instalar nada e o aplicativo não precisa de internet.

Senha de acesso: 2007

Os imóveis e as fotos ficam armazenados apenas no navegador usado para abrir
o arquivo. Se os dados do navegador forem apagados, a lista também será apagada.

Use o botão "Exportar" para gerar um arquivo de backup com todos os imóveis e
fotos. Use "Importar" para restaurar ou mesclar um backup na lista atual.

Como a nota funciona:
- Valor do imóvel, condomínio, tamanho, localização, mobília e garagem formam a média.
- Churrasqueira, sacada e elevador somam 5 pontos cada depois da média.
- A água inclusa desconta R$ 100 do condomínio somente para o cálculo.
- A nota final é limitada ao intervalo de 0 a 100.
